# Contributing to Atom

First off, thanks for taking the time to contribute!

The following is a set of guidelines for contributing to github-final-project and its packages, which are hosted in the [Student](https://github.com/atom) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

This project and everyone participating in it is governed by the [Atom Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [student@github.com](mailto:atom@github.com).
